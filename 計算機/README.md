# 多功能計算機與出題系統

簡介：一個在瀏覽器執行的多功能計算機，支援表達式計算、單變數方程式求解、歷史紀錄（localStorage）與出題/測驗系統。

使用方式：

1. 在瀏覽器中開啟 `index.html`（直接雙擊或用 VS Code Live Server）。
2. 在上方輸入框輸入表達式或方程式：
   - 表達式示例：`2+3*4`, `sin(0.5)`, `2^3`。
   - 方程式示例：`2*x+3=7`（按「求解 x」）。
3. 使用右側面板可查看歷史、匯出/清除歷史，並產生或開始測驗題目。

備註：此專案使用 `math.js`（CDN）做運算與解析。
